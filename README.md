# Smart Deals Platform — صفقات ذكية

منصة عربية RTL لإدارة دورة حياة الصفقات العمومية في الجزائر، تجمع الإدارة المركزية والمصلحة المتعاقدة والمتعامل الاقتصادي ضمن تطبيق ويب واحد.

## المعمارية الفعلية

يعتمد المشروع على **React 19** و**Vite** في الواجهة، و**Express 4** و**tRPC 11** في الخادم، مع **Drizzle ORM** وMySQL/TiDB للبيانات. لا يستخدم Django أو Next.js أو Docker أو PostgreSQL أو Redis.

| المكوّن          | المسار     | الغرض                                         |
| ---------------- | ---------- | --------------------------------------------- |
| الواجهة          | `client/`  | صفحات React، المكونات، السياقات والتنسيق      |
| الخادم           | `server/`  | إجراءات tRPC ومنطق الوصول والتكاملات          |
| البيانات         | `drizzle/` | مخطط Drizzle وسجل migrations القائم           |
| الأنواع المشتركة | `shared/`  | ثوابت وأنواع وعقود مشتركة                     |
| التخزين          | `storage/` | تكامل التخزين الموقّع                         |
| التوثيق          | `docs/`    | المعمارية والتشغيل والأمن والمستندات المرجعية |

## التشغيل المحلي

يتطلب التشغيل Node.js وpnpm واتصال قاعدة البيانات المُدار الذي توفره البيئة. لا تُنشأ ملفات أسرار محلية ولا تُستخدم بيانات إنتاج.

```bash
pnpm install
pnpm dev
```

تعمل الواجهة والخادم معاً على المنفذ 3000 في وضع التطوير. مسار واجهة الإجراءات هو `/api/trpc`؛ لا توجد واجهات Swagger أو ReDoc لأن النظام tRPC-first.

## الفحوص الآمنة

```bash
pnpm check
pnpm lint
pnpm test
```

لا تشغّل `pnpm db:push` ضمن المعاينة أو البيئة المحلية إلا بعد مراجعة migration والموافقة الصريحة؛ هذا الأمر ينشئ ويطبق migrations.

## الإصدارات والتعافي

يُدار المشروع داخل بيئة WebDev. استخدم checkpoint قابل للاسترجاع قبل تغيير البنية أو الإعدادات. راجع [PROJECT_STRUCTURE.md](./PROJECT_STRUCTURE.md) لخريطة المسارات وأوامر التشغيل، و[docs/README.md](./docs/README.md) لفهرس الوثائق.
