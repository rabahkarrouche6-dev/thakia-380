# عقد AI Regulator الاستشاري

## مبدأ الاستخدام

يعرض الجناح الرقابي **قرائن وملاحظات استشارية** مشتقة من السجلات الفعلية. لا يمثل `severity` حكماً قانونياً، ولا يمثل `confidence` احتمال إدانة، ولا يجوز استخدام النتيجة وحدها لإقصاء مورد أو إلغاء صفقة أو اتخاذ قرار تعاقدي.

> جميع النتائج تحتاج إلى مراجعة بشرية موثقة، والتحقق من الوثائق والمعلومات خارج المؤشرات الآلية قبل أي إجراء.

## عقد النتيجة الموحد

| الحقل | المعنى | القيد |
|---|---|---|
| `kind` | `collusion_signal` أو `rfp_observation` أو `tender_risk` | نوع ملاحظة لا نوع مخالفة |
| `tenderId` | معرف الصفقة | داخلي للواجهة المحمية |
| `severity` | `low` أو `medium` أو `high` | شدة إشارة المراجعة فقط |
| `confidence` | `low` أو `medium` أو `high` | جودة/اكتمال الأدلة المتاحة، وليس احتمال المخالفة |
| `title` | عنوان عربي مؤسسي | لا يتضمن اتهاماً |
| `summary` | خلاصة قصيرة | لا تتضمن قراراً نهائياً |
| `evidence[]` | مصدر كل قرينة وقيمتها الآمنة | لا يحتوي proposal خاماً أو وثائق أو PII غير لازم |
| `limitations[]` | ما لا يمكن استنتاجه | إلزامي عند كل نتيجة |
| `recommendedAction` | خطوة مراجعة بشرية | لا ينفذ إجراءً تعاقدياً |

## قرائن collusion MVP

يُحتسب لكل صفقة وبعد فتح العروض فقط: تطابق رقم التسجيل بين موردين مختلفين، تقارب زمني شديد في `submittedAt`، تطابق مبالغ عرضين أو أكثر، وتقارب نصي بسيط على مستوى التطبيع دون حفظ النص في النتيجة. تُنشأ النتيجة فقط إذا وجدت قرينة فعلية. غياب IP أو بصمة جهاز موثق يعني أن النظام لا يذكر IP في النتيجة ولا يدّعي تحليله.

كل مقارنة محصورة داخل الصفقة نفسها، وتعرض معرفات عروض/موردين داخل بوابة regulator فقط. لا تُعرض للمورد أو المصلحة المتعاقدة، ولا تُعاد قبل وجود جلسة فتح.

## قرائن RFP audit MVP

يفحص النصين `title` و`description` للكلمات أو الصيغ التي تستدعي المراجعة، مثل ذكر علامة تجارية دون «أو ما يعادلها»، صياغة حصرية مطلقة، متطلبات خبرة شديدة التحديد، أو وصف قصير جداً يفتقد عناصر تشغيلية واضحة. هذه قواعد لغوية استكشافية وليست قواعد قانونية، ويجب إظهار الحقل والعبارة المطابقة دون إعادة أي وثيقة خاصة.

## `tenderRisk` في النسخة الأولى

لا يقدّم MVP توقعاً إحصائياً للتعثر أو تدني الأسعار لعدم وجود تاريخ كافٍ ومؤشرات موثقة. يمكن إرجاع حالة «بيانات غير كافية» فقط، أو اشتقاق مستوى مراجعة وصفي من اكتمال البيانات وعدد القرائن دون تسميته تنبؤاً.

## Legal advisory

يبقى `assistant.ask` مساعداً تفسيرياً عاماً. لا يحق له اختلاق أرقام مواد أو مصادر. عند عدم توفر corpus قانوني رسمي في النظام، يجب أن يصرح بأن الإجابة ليست استشارة قانونية وأن المرجع النهائي هو النص الرسمي والمستشار المختص. لا تُرسل إلى النموذج بيانات هوية الموردين أو نصوص العروض غير الضرورية.

## الصلاحيات والتدقيق

تُحمى جميع إجراءات `regulator.ai.*` على الخادم بدور `regulator` أو `admin`. يسجل استدعاء التحليل كحدث قراءة آمن دون محتوى حساس، مع نوع التحليل ومعرف الصفقة والنتيجة العامة. لا يسجل الطلب النصي الكامل أو أي مستند أو token.

## حالات الواجهة

تدعم الواجهة التحميل، الخطأ، عدم وجود قرائن، النتائج، وحالة «البيانات غير كافية». وتظهر شارة ثابتة: «مؤشر استشاري — لا يمثل حكماً أو قراراً». لا توجد أزرار إقصاء أو إلغاء أو إسناد داخل الجناح.
