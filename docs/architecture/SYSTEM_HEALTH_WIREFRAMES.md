# SYSTEM HEALTH — HIGH-FIDELITY WIREFRAMES

## النطاق المعتمد

يُنفذ في هذه المرحلة تحسين صفحة الحالة العامة ومؤشر الحالة المصغر، بينما تُوثق غرفة العمليات الداخلية كتصميم وعقد صلاحيات دون تشغيل بيانات وهمية. مصدر الحقيقة الحالي هو `system.status` الذي يفحص قاعدة البيانات وتوفر إعدادات المصادقة والتخزين.

## 2. غرفة العمليات الداخلية

تظهر مستقبلاً خلف `adminProcedure` أو دور تشغيلي مخصص، ولا تُبنى على بيانات عامة. تشمل مناطق: صحة البنية التحتية، صحة AI، الأمن، وسير الحوادث. كل بطاقة تحمل مصدر القياس والوقت وحالة توفر البيانات. لا تعرض أي بطاقة «دقة» أو «سلامة عقد» قبل وجود مصدر موثق.

## الحالات

| الحالة | اللون | معنى العرض |
|---|---|---|
| operational | أخضر | الفحص الأخير نجح |
| degraded | أصفر | فشل جزئي أو إعداد ناقص |
| unavailable | رمادي | لا يوجد مصدر قياس أو لم يُفعّل |
| incident | أحمر | يُستخدم فقط بعد ربط حادثة موثقة |

## قواعد الوصول

صفحة الحالة العامة لا تكشف سجلات أو معرفات داخلية. غرفة العمليات لا تُربط بواجهة عامة، وتحتاج إجراءً خادمياً محمياً وتدقيقاً لكل قراءة حساسة إذا أضيفت لاحقاً.
