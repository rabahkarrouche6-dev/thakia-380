# AUTHORITY RFP ADVISORY IMPLEMENTATION REPORT

## القرار التنفيذي

تم تنفيذ MVP محدود لمساعد استشاري لتدقيق وصياغة بيانات دفتر الشروط داخل بوابة المصلحة المتعاقدة. المساعد لا ينشئ الصفقة، ولا يعدّلها، ولا ينشرها، ولا يقدم قراراً قانونياً أو تعاقدياً.

## ما تم تنفيذه

أضيف محرك `server/authorityAi.ts` الذي يجمع بين فحوص حتمية قابلة لإعادة الإنتاج ومراجعة لغوية منظمة عبر `invokeLLM`. تشمل الفحوص طول العنوان والوصف، غياب الموقع أو الميزانية، صلاحية الموعد وفق وقت الخادم، والصياغات الحصرية أو ذكر العلامة/الموديل دون إشارة تكافؤ قريبة. نتائج LLM مقيدة بمخطط JSON، ويعود النظام إلى الفحص الحتمي عند فشل النموذج أو عدم صلاحية الاستجابة.

أضيف المسار المحمي `authority.ai.reviewTender` في `server/routers.ts`. يتحقق الخادم من الدور، ملكية الصفقة، وحالة `draft`. يسجل الإجراء حدث التدقيق `authority_rfp_advisory_reviewed` بعد النجاح، مع عدد الملاحظات وبيان استخدام LLM دون تسجيل نص الاستجابة أو محتوى الوثائق.

أضيفت واجهة `client/src/pages/AuthorityRfpAdvisor.tsx` داخل الخطوة الثالثة من `AuthorityTenderCreate`. تعرض الواجهة حالة عدم حفظ المسودة، التحميل، الفشل وإعادة المحاولة، النتيجة الفارغة، الملاحظات المصنفة، الأدلة، التوصيات، وحدود الاستخدام. بقيت أزرار الحفظ والنشر مستقلة عن نتيجة المساعد.

## الصلاحيات والبيانات

المساعد لا يعمل إلا على صفقة محفوظة في قاعدة البيانات. يمنع الخادم الوصول إلى صفقة جهة أخرى عبر التحقق من `authorityId`. يعتمد التحليل على حقول `Tender` الحالية فقط، ولا يرسل وثائق الصفقة أو مفاتيح التخزين أو بيانات المستخدمين إلى LLM.

## الاختبارات والتحقق

أضيف `server/authorityAi.test.ts` لاختبار اكتمال المسودة، نقص الحقول، الصياغات الحصرية، وموعد غير صالح. نجحت مجموعة التحقق كاملة: **17 ملف اختبار و64 اختباراً**. نجح فحص TypeScript والبناء. أُجري تحقق بصري للواجهة العامة العربية RTL على سطح المكتب، مع بقاء اختبار مسار المستخدم المخول بحاجة إلى جلسة دخول فعلية لإنشاء مسودة وتشغيل الإجراء من الواجهة.

## القيود المتبقية

لا يوجد في النموذج الحالي جدول كميات أو معايير تنقيط أو قائمة وثائق إلزامية أو مصدر قانوني رسمي؛ لذلك لا يدعي المساعد فحصها. لا يشمل الإصدار التصدير الرسمي، OCR، أو اعتماد النص النهائي. كما أن مراجعة LLM تظل advisory ويجب أن تخضع لمراجعة بشرية قبل النشر.
