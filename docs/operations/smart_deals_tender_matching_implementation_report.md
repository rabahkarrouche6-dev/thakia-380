## Actual Data Sources

يستخدم التنفيذ `Profile.organizationName`, `Profile.address`, `Profile.completion`، وحقول الصفقة `title`, `description`, `category`, `location`, `deadline`, `status`, `reference`, و`id`. لا تُستخدم الخبرة أو الشهادات أو القدرة أو حجم المؤسسة أو الأداء السابق لأنها غير موجودة كبيانات منظمة موثوقة في المخطط الحالي.

## Algorithm

تُستبعد الصفقة إذا لم تكن في حالة `published` أو إذا كان موعدها النهائي منتهياً وفق وقت الخادم الممرر إلى الدالة. الصفقة المستبعدة تحصل على `Not Eligible` ودرجة صفر وسبب صريح. للصفقات الباقية، الأوزان الحالية هي: الفئة 45%، التشابه النصي 35%، الموقع 10%، جاهزية الملف 10%. يعاد تطبيع الأوزان المتاحة مع حد أدنى 45%.

التطبيع يدعم العربية وبعض المرادفات العربية والفرنسية والإنجليزية للفئات الموجودة، دون ادعاء استخدام embeddings أو TF-IDF. التصنيفات هي `Highly Relevant`, `Relevant`, `Potential Fit`, `Low Fit`، بينما `Not Eligible` مخصص للبوابة التشغيلية الزمنية/الحالية وليس حكماً قانونياً.

## API and Permissions

الإجراء `tenders.recommended` محمي بدور المورد، ولا يستقبل معرفات أو ملفاً من العميل. يقرأ الخادم هوية الحساب والملف والصفقات المنشورة، ويعيد حتى خمس نتائج مرتبة. لا يعرض عروض موردين آخرين أو وثائق أو أسراراً، ولا يغير أي حالة في Tender أو Bid.

## UI Contract

يظهر القسم في الصفحة الرئيسية للمورد فقط، ويتضمن عنوان الصفقة، المرجع، الدرجة، التصنيف، أسباباً مختصرة، ورسالة توضح أن المطابقة إرشادية. زر «مراجعة التفاصيل» يعيد إلى قائمة الصفقات المنشورة الحالية، وهي المسار الحقيقي المتاح في MVP. تُعالج حالات التحميل والفشل والنتائج الفارغة مع CTA لاستكشاف القائمة.

## Privacy and Bias Controls

لا تُرسل كلمات مرور أو وثائق أو محتوى وثائق أو بيانات منافسين أو سمات حساسة. لا يعاقب المحرك المورد الجديد بسبب غياب التاريخ، ولا يستخدم غياب الشهادات أو القدرة كسبب إقصاء لأنها غير متاحة. اسم المؤسسة ليس بديلاً كاملاً عن النشاط التجاري؛ لذلك يظهر ذلك كقيد دقة، ولا تتحول الدرجة إلى قرار قانوني.
