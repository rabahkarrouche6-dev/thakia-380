# التحقق البصري — رحلة المتعامل

تمت معاينة صفحة الهبوط كاملة على سطح المكتب بعرض 1280px وعلى الهاتف بعرض 390px.

على سطح المكتب ظهر القسم داخل حاوية كحلية مستقلة، مع مسار عمودي مركزي، خط زمردي متدرج، أربع نقاط مرقمة، وبطاقات متبادلة يميناً ويساراً. النص مقروء، والـ CTA واضح، ولا توجد نسب أو وعود غير مثبتة.

على الهاتف تحول المسار إلى محور جانبي بمحاذاة البطاقات، وأصبحت المحطات عمودية في عمود واحد دون تمرير أفقي. بقيت البطاقات قابلة للقراءة، والنصوص والزر ضمن مساحة العرض.

تم التحقق من أن القسم لا يعتمد على hover لفهم المحتوى، وأن العناصر الزخرفية موسومة `aria-hidden`. الحركة لها fallback عند غياب `IntersectionObserver`، وتخضع لـ `prefers-reduced-motion` عبر أصناف `motion-reduce`.

ملاحظة تقنية: البناء أظهر تحذيرات حجم chunks موجودة في حزمة المشروع العامة، دون أخطاء TypeScript أو فشل build ناتج عن القسم الجديد.
