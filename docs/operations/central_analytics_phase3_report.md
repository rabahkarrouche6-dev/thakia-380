# CENTRAL ANALYTICS — PHASE 3 SERVER QUERY CONTRACTS

## النطاق

نُفذت عقود الاستعلامات الخادمية الخاصة بـ **Overview MVP** فقط. لم تُنفذ أي واجهة جديدة، ولم تُضف جداول أو حالات قاعدة بيانات أو صلاحيات جديدة، ولم تُنشأ charts.

| الملف | التغيير |

| `server/routers.ts` | إضافة الإجراء المحمي `regulator.overview`. |

## عقد الاستعلام

يستدعي `regulator.overview` helper الخادم `getRegulatorOverview()` ويعيد بنية ثابتة قابلة للاستهلاك من الواجهة لاحقاً:

| الحقل | النوع | المصدر | المعنى |
|---|---|---|---|
| `stats.tenders` | number | `tenders` | العدد الكلي للصفقات الموجودة. |
| `stats.published` | number | `tenders.status` | الصفقات ذات الحالة `published`. |
| `stats.evaluation` | number | `tenders.status` | الصفقات ذات الحالة `evaluation`. |
| `stats.bids` | number | `bids` | العدد الكلي للعروض. |
| `stats.audits` | number | سجلات التدقيق المسترجعة | عدد سجلات التدقيق في نافذة النشاط الحالية، وهي آخر 8 سجلات. |
| `tenderStatusCounts` | `Record<string, number>` | `tenders.status` | توزيع الصفقات حسب الحالات الموجودة فعلياً، دون إضافة حالات جديدة. |
| `recentAudit` | `AuditLog[]` | `auditLogs` | آخر 8 سجلات مرتبة تنازلياً حسب `createdAt`. |

في حالة عدم توفر قاعدة البيانات يعيد helper بنية صفرية آمنة بدلاً من بيانات وهمية، مع مصفوفة نشاط فارغة وتوزيع حالات فارغ.

## الصلاحيات

الإجراء محمي بواسطة `roleProcedure(["regulator", "admin"])`. لذلك يُسمح بالقراءة لدور regulator وadmin فقط، وتُرفض طلبات supplier وauthority بخطأ `FORBIDDEN`. العقد للقراءة فقط ولا يضيف أي mutation أو مسار لاتخاذ قرار تعاقدي.

## الاختبارات والتحقق

نجح فحص TypeScript دون أخطاء. نجحت مجموعة Vitest كاملة: **8 ملفات اختبار و25 اختباراً**. يغطي الاختبار الجديد شكل الاستجابة الأساسية، وجود توزيع الحالات والنشاط، ومنع supplier وauthority من الوصول إلى عقد Overview MVP. كما بقيت اختبارات regulator الحالية للقراءة فقط واختبارات منع العمليات التعاقدية ناجحة.

## ما لم يُنفذ

لم تُنفذ مكونات `RegulatorOverview` أو أي تغيير في `CentralAdminPortal`. لم تُنفذ الاتجاهات الزمنية أو الفلاتر أو drill-down أو التنبيهات أو مؤشرات المخاطر أو الرسوم البيانية. كما لم تُضف pagination أو aggregation SQL محسّنة؛ التجميع الحالي يتم في helper الخادمي على الصفوف المسترجعة، وهو مناسب لعقد MVP الحالي ويحتاج تحسيناً قبل أحجام إنتاجية كبيرة.

## المخاطر والقرارات اللاحقة

حقل `stats.audits` يعكس نافذة آخر 8 سجلات وليس العدد التاريخي الكلي، لأن العقد يعتمد على نشاط Overview الحالي. ينبغي تثبيت هذا التعريف في PHASE 3 UI أو فصل `recentAuditCount` عن أي KPI تاريخي قبل العرض. كما ينبغي لاحقاً إضافة استعلامات زمنية وفلاتر خادمية بعقود مستقلة، وعدم نقل منطق الصلاحيات إلى الواجهة.
