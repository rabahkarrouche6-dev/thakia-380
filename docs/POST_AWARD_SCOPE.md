# نطاق ما بعد الإسناد

## الحالة الحالية

يحتوي المشروع على `awardDecisions` لتسجيل قرار الإسناد أو الإلغاء، لكنه لا يحتوي حالياً على نموذج عقد مستقل أو دورة تنفيذ للعقد أو أوامر تغيير أو دفعات أو مؤشرات إنجاز.

## قرار النطاق

يُعد نطاق الـ Pilot من التخطيط إلى النشر والاستلام والفتح والتقييم وقرار الإسناد فقط. لا تُعرض واجهة أو ادعاءات تنفيذية للعقد بعد الإسناد ما لم توجد كيانات وإجراءات وصلاحيات وسجل تدقيق مستقل يدعمها.

## شروط فتح V1

قبل إضافة دورة العقود يجب تصميم نموذج العقد، الأطراف، تاريخ السريان، الضمانات، مراحل التنفيذ، التعديلات، حالات التعليق والإنهاء، المدفوعات، والمرفقات، مع ربط كل انتقال بقرار مخول وسجل تدقيق واختبارات IDOR وتنافس.
