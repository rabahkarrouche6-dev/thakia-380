# خط أساس الأداء

## النطاق

تم قياس مجموعة اختبارات الخادم التي تغطي صلاحيات الأدوار، فتح الأظرفة، أمن الوثائق، وقناة SSE. هذا القياس ليس بديلاً عن benchmark على قاعدة بيانات إنتاجية أو اختبار حمل HTTP، لكنه خط أساس قابل للتكرار داخل بيئة الاختبار الحالية.

## القياس الحالي

| المؤشر | القيمة |
|---|---:|
| زمن أمر Vitest الكامل من ساعة النظام | 3.268 ثانية |
| زمن Vitest الداخلي | 1.83 ثانية |
| الاختبارات الناجحة | 27 |
| الاختبارات المتخطاة | 1 |
| ملفات الاختبار | 4 |
| أبطأ مجموعة ظاهرة | `server/permissions.test.ts` بحوالي 998ms |

## الاستنتاج المنضبط

لا يوجد دليل كافٍ بعد لاقتراح `select_related` أو `prefetch_related` أو فهرس جديد؛ القياس الحالي لا يقيس استعلامات MySQL/TiDB على بيانات تشغيلية. الخطوة التالية الصحيحة هي تشغيل benchmark تكاملي على قاعدة بيانات اختبارية تحتوي حجماً اصطناعياً معلناً، مع قياس عدد الاستعلامات، p50/p95 للكمون، واستهلاك الذاكرة قبل تعديل ORM.

اختبار المفتاح الإنتاجي ما يزال متخطياً عمداً، لذلك لا يمثل هذا الخط الأساس جاهزية التشفير الإنتاجي.
