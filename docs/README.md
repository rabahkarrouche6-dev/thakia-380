# فهرس وثائق Smart Deals

| المجلد          | المحتوى                                                    |
| --------------- | ---------------------------------------------------------- |
| `architecture/` | قرارات التصميم، خطط التنفيذ، أبحاث الواجهة وتصميمات المسار |
| `operations/`   | تقارير التشغيل والمعاينة والصحة والأداء والتوطين           |
| `security/`     | مراجعات الوصول والتشفير وOAuth وملفات التهديد              |
| `legal/`        | مساحة للمستندات القانونية المعتمدة فقط                     |

هذه الملفات توثيقية ولا تحتوي أسراراً أو ملفات بيئة. تُحفظ وثائق جديدة بحسب موضوعها، ولا تُستخدم كبديل عن التحقق البرمجي أو سجلات التدقيق التشغيلية.
