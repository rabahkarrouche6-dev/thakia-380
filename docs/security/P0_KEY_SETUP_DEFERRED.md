# قرار تأجيل ربط مفتاح التشفير الإنتاجي

بتاريخ 2026-08-18، تم تخطي مرحلة تزويد والتحقق من `BID_ENCRYPTION_MASTER_KEY` بناءً على طلب المستخدم. لذلك تبقى خدمة `server/crypto/bidEncryption.ts` مكوّناً معزولاً للاختبار فقط، ولا تُستخدم حالياً داخل مسارات تقديم العروض أو رفع الوثائق أو جلسة فتح الأظرفة.

## الأثر

لا يمكن اعتبار سرية العروض والوثائق مكتملة إنتاجياً. لا توجد migration أو dual-write أو إعادة تشفير للبيانات الحالية، ولم تُغيّر روابط التخزين. اختبار المفتاح المهيأ فشل لأن القيمة الحالية لا تمثل 32 بايت بالضبط.

## شرط الاستئناف

قبل أي ربط إنتاجي يجب توفير `BID_ENCRYPTION_MASTER_KEY` صحيح يمثل 32 بايت بصيغة Base64 أو Hex، ثم نجاح اختبار round-trip بالمفتاح المهيأ. بعد ذلك يلزم تصميم migration غير تدميرية، ونسخة احتياطية قابلة للاسترجاع، واختبارات منع الفتح المبكر والتلاعب والتنافس على قاعدة بيانات اختبارية.

> هذه الحالة لا تغلق P0 ولا تغيّر حكم الجاهزية: المنصة تبقى Pilot Only في نطاق مضبوط إلى أن تُغلق فجوة التشفير وسرية التخزين.
