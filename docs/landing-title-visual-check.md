# تحقق بصري — عنوان صفحة الهبوط

تمت معاينة صفحة الهبوط بعد استبدال العبارة السابقة باسم «صفقات ذكية».

- سطح المكتب 1280×720: ظهر الاسم بحجم كبير، مع تدرج ذهبي/أبيض لكلمة «صفقات» وتوهج أخضر لكلمة «ذكية»، دون قص أو تداخل مع البطاقة الجانبية.
- الهاتف 390×844: بقي العنوان واضحاً داخل Hero، وتوزعت الكلمتان عمودياً مع مساحة كافية للنص والأزرار، دون قص أفقي.
- RTL: ترتيب النص والمحاذاة مناسبان للواجهة العربية.
- التباين: العنوان مقروء على الخلفية الداكنة، مع الحفاظ على زر الدعوة للإجراء.
